# 扩展的合成数据集 (Extended Synthetic Dataset)

## 📊 数据集概览

本数据集是对原有 `synthetic` 数据集的扩展，新增了大量东南亚和东亚语言支持。

### 🎯 主要改进

1. **语言覆盖度大幅提升**：从 7 种语言扩展到 29 种语言
2. **新增东南亚语言**：缅甸语(my)、高棉语(km)、老挝语(lo)、他加禄语(tl)
3. **新增东亚语言**：繁体中文(zh-Hant)、蒙古语(mn)
4. **新增南亚语言**：印地语(hi)、孟加拉语(bn)、乌尔都语(ur)、泰米尔语(ta)、泰卢固语(te)、卡纳达语(kn)、马拉雅拉姆语(ml)、僧伽罗语(si)、尼泊尔语(ne)
5. **新增中东语言**：阿拉伯语(ar)、波斯语(fa)

### 📈 数据集统计

- **总样本数**: 580 个
- **支持语言**: 29 种
- **每种语言样本数**: 20 个
- **图像尺寸**: 1200x(动态高度)
- **文本长度**: 平均 50+ 词/字符

## 🌏 支持的语言分类

### 东亚语言 (5种)
- `zh` - 简体中文
- `zh-Hant` - 繁体中文  
- `ja` - 日语
- `ko` - 韩语

- `id` - 印尼语
- `ms` - 马来语
- `tl` - 他加禄语(菲律宾语)

### 南亚语言 (9种)
- `hi` - 印地语
- `bn` - 孟加拉语
- `ur` - 乌尔都语
- `ta` - 泰米尔语
- `te` - 泰卢固语
- `kn` - 卡纳达语
- `ml` - 马拉雅拉姆语
- `si` - 僧伽罗语
- `ne` - 尼泊尔语

### 欧洲语言 (5种)
- `en` - 英语
- `fr` - 法语
- `de` - 德语
- `es` - 西班牙语
- `ru` - 俄语

### 中东语言 (2种)
- `ar` - 阿拉伯语
- `fa` - 波斯语

## 🛠️ 使用方法

### 1. 生成数据集
```bash
cd /root/lhy/paddleocr/benchmarks
python3 gen_synthetic_extended.py --n 20
```

### 2. 测试数据集
```bash
python3 test_extended_synthetic.py
```

### 3. 查看特定语言样本
```bash
ls synthetic/zh/          # 查看中文样本
ls synthetic/km/          # 查看高棉语样本
ls synthetic/my/          # 查看缅甸语样本
```

### 4. 运行基准测试
```bash
python3 run_benchmark_synthetic.py
```

## 🔧 技术特性

### 字体支持
- 使用 Noto 字体系列确保跨语言字符显示
- 针对不同语言使用专门的字体文件
- 自动字体回退机制

### 文本生成
- 每种语言包含 5 个基础文本模板
- 使用连接词和引号增强文本多样性
- 目标长度：50+ 词/字符

### 图像渲染
- 标准宽度：1200px
- 动态高度：根据文本长度调整
- 白色背景，黑色文本
- 适当的边距和行间距
