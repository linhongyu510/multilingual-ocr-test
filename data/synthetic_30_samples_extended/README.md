# 扩展版多语言合成数据集 (Extended Multilingual Synthetic Dataset)

## 📊 数据集概览

本数据集是对原有 `synthetic_30_samples_final` 数据集的扩展，新增了8种东南亚和东亚语言支持。

### 🎯 主要改进

1. **语言覆盖度大幅提升**：从 16 种语言扩展到 24 种语言
2. **新增东南亚语言**：老挝语(lo)、印尼语(id)、越南语(vi)、菲律宾语(tl)、马来语(ms)、柬埔寨语(km)
3. **新增东亚语言**：蒙古语(mn)、维吾尔语(ug)
4. **解决乱码问题**：使用最佳字体，确保所有语言正确显示
5. **完整文本样本**：每种语言30个完整的文本样本

### 📈 数据集统计

- **总样本数**: 720 个
- **支持语言**: 24 种
- **每种语言样本数**: 30 个
- **图像尺寸**: 1200x300
- **文本长度**: 平均 50+ 词/字符

## 🔧 技术特点

1. **无乱码设计**：使用Noto字体系列，确保所有Unicode字符正确显示
2. **完整文本**：每个样本都是完整的句子或段落
3. **标准格式**：每个图像都有对应的.txt和.json标注文件
4. **UTF-8编码**：所有文本文件使用UTF-8编码，支持多语言
5. **高质量图像**：1200x300分辨率，适合OCR识别

## 🚀 使用方法

1. **直接使用**：可以直接用于OCR模型训练和测试
2. **语言识别**：支持24种语言的文本识别
3. **多语言OCR**：适合多语言OCR系统的开发和测试

## 📝 注意事项

- 所有文本文件使用UTF-8编码
- 图像文件为PNG格式，已优化
- 标注文件包含完整的元数据信息
- 支持从右到左书写的语言（如阿拉伯语、维吾尔语）
